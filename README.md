# Document Creator Studio

Document Creator Studio is an online tool that automatically converts website copy JSON files into formatted, client-ready Word documents (`.docx`).

**Launch the App:** [https://content-document-maker.streamlit.app/](https://content-document-maker.streamlit.app/)

---

## What It Does

When creating website content, copy is often generated or exported as structured JSON containing multiple pages (Home, Services, Areas, Contact). Formatting this copy manually into clean Word documents with tables, headings, and branding is tedious and repetitive.

**Document Creator Studio handles the formatting for you:**
- Takes your content JSON file and turns it into a styled Word document in seconds.
- Automatically structures each page (Home, Service pages, and Contact page) with the correct headings, subheadings, and sections.
- Formats page titles, meta descriptions, and $H1$ headlines into clean summary tables.
- Organizes Unique Selling Points (USPs) into highlighted 3-column tables.
- Inserts service overviews, FAQs, process steps, value propositions, and Call-to-Action (CTA) banners.
- Generates a complete Site Map on the front cover listing all created pages.
- Varies call-to-action button wording across pages so your document reads naturally instead of repeating the same phrase.

## How to Use the Tool

Using the tool online takes just three simple steps:

### 1. Open the Web App
Go to **[https://content-document-maker.streamlit.app/](https://content-document-maker.streamlit.app/)** in any browser.

### 2. Add Your Content
Choose whichever method is easiest:
- **Upload File:** Drag and drop your `.json` file into the upload box.
- **Paste Text:** Switch to "Paste JSON Text" and paste your copy directly.

*(Tip: Click **"Load Example JSON"** in the sidebar if you want to test the tool with sample content first.)*

### 3. Review and Download
- Check the **Live Document Preview** on the right to see the detected pages, titles, and structure.
- *(Optional)* Give your file a custom name in the **Custom Output Filename** box.
- Click **"Generate Word Document"** and your `.docx` file will download immediately.

## Pages and Content Supported

The tool automatically formats all common website page types:

| Page Type | Included Sections |
| :--- | :--- |
| **Front Cover** | Client details, opening hours, review notes, and an automatic Site Map index |
| **Home Page** | Header table, core message, hero button, 3 USPs, main introduction, service summaries, "Why Choose Us" highlights, process steps, value propositions, and CTA table |
| **Service & Location Pages** | Header table, key highlights, 4 content body sections, in-text enquiry buttons, key propositions, frequently asked questions (FAQs), and CTA table |
| **Contact Us Page** | Header table, summary, 3 USPs, enquiry options, and a contact form blueprint |

---

## Master Template Options

- **Default Template (Recommended):** The tool comes pre-loaded with a master Word template that provides clean fonts, colors, and layout out of the box. You can also download a copy of this template directly from the sidebar.
- **Custom Template:** If your team or agency has its own specific `.docx` layout, select **"Upload Custom Template (.docx)"** in the sidebar to apply your own styles.
